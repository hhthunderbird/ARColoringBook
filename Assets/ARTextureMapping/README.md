# Felina AR Texture Mapping

Toolkit for Unity AR Foundation image tracking: real-time texture capture, prefab spawning, and material updates. Supports Unity 2019.4+ and AR Foundation 4.x+.

## Overview
Felina AR Texture Mapping extends Unity AR Foundation’s image tracking with real-time texture capture, prefab spawning, and dynamic material updates. It features GPU-accelerated unwarp, native C++ quality and stability checks, and supports Standard, URP, and HDRP shaders. The package includes developer tools, sample scenes, and full documentation. Compatible with Unity 2019.4 LTS and newer, and AR Foundation 4.x or higher, for iOS and Android. No macOS runtime support.

## Features
- Works with AR Foundation 4.x+ (no known max version)
- Real-time texture capture and unwarp (GPU-accelerated)
- Quality and stability detection (native C++)
- Prefab spawning and material updates for tracked images
- Native plugins: `InternalSolver.so` (Android armv7/arm64), `InternalSolver.a` (iOS)
- Supports Standard, URP, HDRP, and custom shaders
- Developer tools: package validator, sample manager, custom inspectors
- Example scene and full documentation

## Platform Support
- iOS (ARKit)
- Android (ARCore)
- Editor support for configuration and setup (no runtime tracking)
